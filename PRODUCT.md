# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
- **Citizens**: Individuals experiencing supernatural or anomalous occurrences who need to report emergencies and track specialist intervention.
- **Responders**: Accredited paranormal specialists (exorcists, ghost hunters, clairvoyants, relic researchers) deployed to ground-zero containment operations.
- **Dispatchers**: Operations officers monitoring the tactical radar, assessing threat classifications, and assigning appropriate field response units.
- **Administrators**: Command HQ personnel managing system accounts, credentialing specialists, overseeing dossiers, and issuing high-priority alerts.

## Product Purpose
SpectRescue is an emergency response and dispatch operations platform specifically engineered for paranormal and supernatural crises, connecting affected citizens with field specialists.

## Positioning
A tactical command console combining real-time anomaly geolocation, accredited specialist triage, single-active-mission locking, and verifiable post-containment resolution dossiers.

## Operating Context
Desktop and mobile web interfaces operated across ambient lighting conditions, from high-threat nighttime emergency reporting by citizens to continuous multi-monitor dispatch oversight.

## Capabilities and Constraints
- Role-based access control (Citizen, Responder, Dispatcher, Admin) with defense-friendly, student-maintainable architecture.
- Real-time Leaflet ground-zero coordinate mapping and field evidence capture.
- Mission deployment lock preventing concurrent multi-assignment of field units.
- Formal containment reporting lifecycle from initial triage to verified resolution.
- Responsive dark-mode tactical interface built with Laravel 11, Blade, and Tailwind CSS.

## Brand Commitments
- **Name**: SPECTRESCUE (Paranormal Dispatch HQ)
- **Palette**: Deep void slate (`slate-950` / `slate-900`), tactical cyan glow (`cyan-400` / `cyan-500`), alert amber (`amber-400`), containment emerald (`emerald-400`), emergency crimson (`red-500`).
- **Voice**: Professional, authoritative paranormal crisis agency.
